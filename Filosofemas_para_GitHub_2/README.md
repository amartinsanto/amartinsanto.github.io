# Filosofemas

Blog personal de Ángel Martín Santo. Primera edición: 28 entradas procedentes del blog del autor en PortalEdu, recogidas el 6 de noviembre de 2026.

## Publicar en GitHub Pages

1. Crear el repositorio público `amartinsanto.github.io` en la cuenta `amartinsanto`.
2. Subir el contenido de esta carpeta a la raíz del repositorio. `index.html` debe estar junto a `style.css`, `search.js` y las carpetas `entradas` e `imagenes`.
3. En Settings → Pages, seleccionar Deploy from a branch, rama `main`, carpeta `/ (root)` y Save.
4. La dirección prevista es https://amartinsanto.github.io/ . La publicación puede tardar unos minutos.

El sitio utiliza HTML, CSS y JavaScript sin dependencias. Se puede abrir `index.html` directamente en el ordenador para revisarlo antes de publicar.

## Contenido y actualizaciones

Los textos mantienen el contenido de las publicaciones originales. Las imágenes conservan los créditos que figuraban en las entradas. Los vídeos y documentos externos se abren desde sus enlaces originales.

Esta primera versión es estática. No sincroniza automáticamente con PortalEdu ni incluye un editor de WordPress. Para añadir entradas, hay que crear su página y actualizar el índice y sus datos de búsqueda, o adaptar posteriormente el proyecto a un generador de blogs.

No se ha añadido ninguna licencia nueva sobre los textos o las imágenes de terceros.
